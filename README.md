# Tío Leo Café & Bistro Website

A modern, responsive website for Tío Leo Café & Bistro, featuring an authentic Costa Rican menu and online ordering capabilities.

## Features

- Responsive design for all devices
- Digital menu with QR code access
- Beautiful food photography
- Easy navigation
- Contact information and opening hours
- Online reservation system

## Technologies Used

- HTML5
- CSS3
- Modern CSS Features (Grid, Flexbox, Animations)
- Responsive Images
- Font Awesome Icons

## Local Development

1. Clone the repository:
```bash
git clone https://github.com/your-username/tio-leo-menu.git
```

2. Open the project folder:
```bash
cd tio-leo-menu
```

3. Open `index.html` in your browser to view the site.

## Deployment

This site is deployed on Netlify. Any changes pushed to the main branch will automatically trigger a new deployment.
